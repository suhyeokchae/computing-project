## 3. 감정 범주와 분석 방법

### 3.1 감정 범주 (8개)

| 범주 | 정의 | 색 |
|---|---|---|
| 슬픔 | 잃어버림이나 이별 때문에 마음이 아프고 무너지는 정서 | 파랑 |
| 그리움 | 곁에 없는 사람·장소·시간을 다시 만나고 싶어 하는 정서 | 보라 |
| 사랑·헌신 | 대상을 아끼고 그를 위해 자신을 내어 주려는 정서 | 분홍 |
| 원망·한 | 풀리지 않은 억울함과 서러움이 마음에 맺힌 정서 | 빨강 |
| 희망·의지 | 어려움 속에서도 앞으로 나아가려는 기대와 다짐 | 주황 |
| 기쁨·생동 | 생명력과 즐거움이 차오르는 밝은 정서 | 노랑 |
| 평온·관조 | 한 걸음 물러서서 대상을 고요히 바라보는 정서 | 초록 |
| 경외·신비 | 알 수 없는 큰 존재 앞에서 느끼는 경이로움과 숭고함 | 청록 |

예시 앱의 "성찰·부끄러움" 대신 한용운 「알 수 없어요」, 변영로 「논개」의 숭고한 정서를 담기 위해 **경외·신비**를 새로 두었고, "원망·미움"을 한국 시의 정서에 맞게 **원망·한**으로 넓혔습니다.

### 3.2 분석 방법: A. 감정 사전 + 해석 프로필 결합 (method: hybrid)

1. **전처리**: 본문을 줄바꿈으로 나누고, 빈 줄(연 구분)은 분석 행에서 뺍니다.
2. **사전 매칭**: 8개 범주에 범주당 14~20개, 모두 135개의 시어(어간 위주)를 직접 정했습니다. 모든 시어를 긴 것부터 정렬해 하나의 정규식으로 만들어, '옛 탑'(경외)과 '옛'(그리움), '진달래꽃'(사랑)과 '달래'(기쁨)처럼 겹치는 시어가 두 번 세어지지 않게 했습니다.
3. **시 단위 비율**: v_lex(e) = 범주 e의 감지 수 / 전체 감지 수
4. **해석 프로필과 결합**: 시마다 해석에 근거한 정서 강도(0~1)를 정하고 합계 1로 정규화(p̂)한 뒤
   `v(e) = normalize((1 − w)·p̂(e) + w·v_lex(e))` 로 섞습니다. 기본값 w = 0.5.
5. **유사도**: 감정 벡터끼리 코사인 유사도를 계산해 높은 순으로 3편을 추천합니다.
6. **비율 표시**: 반올림해도 합계가 정확히 100%가 되도록 최대 잔여 방식으로 반올림합니다.
7. 직접 입력한 시는 해석 프로필이 없으므로 감정 사전만으로 분석합니다.

감정 사전 전체는 `index.html`의 `LEX`에 있습니다. (예시 앱 사전을 쓰지 않고 새로 작성)

## 4. 검증 사례 (계산 결과와 해석이 어긋나는 경우)

아래 수치는 감정 사전만 쓴 경우(w = 100%)입니다.

### 사례 1. 「진달래꽃」 — 반어와 동음이의어
- **결과**: 사랑·헌신 38%, **원망·한 37%**, 슬픔 25%. 원망이 거의 지배 정서와 같은 수준으로 나옵니다.
- **해석**: 화자는 떠나는 임을 원망하기보다 슬픔을 억누르며 헌신하는 태도를 보입니다.
- **원인**: '역겨워'가 두 번 나오고 '즈려밟고'가 원망으로 잡혔습니다. 또 '아름 따다'의 '아름'은 '한 아름'(양)인데 '아름답다'의 어간으로 잘못 잡혀 사랑으로 세어졌습니다. '죽어도 아니 눈물 흘리우리다'는 울지 않겠다는 반어인데 '죽', '눈물'이 그대로 슬픔으로 세어졌습니다.
- **개선**: 반어가 자주 쓰이는 "아니 ~리다" 같은 부정 표현 앞뒤의 시어는 점수를 낮추고, '아름 따다'처럼 뒤 낱말로 뜻이 갈리는 시어는 '아름다'까지 맞춰야 인정하도록 바꿉니다. 웹앱에서는 해석 프로필을 50% 섞어 원망을 26%로 낮췄습니다.

### 사례 2. 「논개」 — 배경 소재가 정서로 잡힘
- **결과**: **평온·관조 33%가 지배 정서**, 사랑·헌신 20%, 희망·의지 20%.
- **해석**: 논개의 의로운 죽음을 기리는, 뜨겁고 숭고한 시입니다. 평온과는 거리가 멉니다.
- **원인**: 후렴 "그 물결 위에"가 세 번 반복되고 '흐르는 강물'까지 있어 자연 소재(물결·강물·흐르)가 평온으로 다섯 번 세어졌습니다. 반대로 '붉은 마음', '꽃다운 혼'처럼 핵심 정서를 담은 비유는 사전에 없어 잡히지 않았습니다. '거룩한 분노'의 '분노'는 원망·한으로 세어졌지만 여기서는 의로운 분노입니다.
- **개선**: 후렴처럼 반복되는 행은 한 번만 세고, 자연 소재는 정서 시어가 아니라 '소재'로 따로 분류합니다. '거룩한 분노'처럼 수식어가 붙은 구는 구 단위로 사전에 넣습니다.

### 사례 3. 「빼앗긴 들에도 봄은 오는가」 — 역설적 배경
- **결과**: **기쁨·생동 35%가 지배 정서**, 평온·관조 20%, 원망·한 18%.
- **해석**: 국권을 잃은 비애와 저항 의식이 주제이며, 봄의 기쁨은 마지막 행에서 "봄조차 빼앗기겠네"로 뒤집힙니다.
- **원인**: '봄', '웃', '반갑', '춤' 등 밝은 시어가 많이 나와 비율이 기쁨으로 쏠렸습니다. 사전은 시 전체의 구조(밝은 장면 → 마지막 반전)를 보지 못하고, '푸른 웃음 푸른 설움'처럼 기쁨과 슬픔이 한 행에 겹치는 역설도 각각 따로 셉니다.
- **개선**: 첫 행과 마지막 행처럼 주제를 담은 행에 가중치를 더 주거나, '그러나' 같은 전환어 뒤의 행에 가중치를 주는 방법을 쓸 수 있습니다. 웹앱에서는 해석 프로필을 섞으면 원망·한이 22%로 올라갑니다.

### 사례 4. 「가는 길」 — 화자를 재촉하는 자연
- **결과**: **평온·관조 56%가 지배 정서**, 그리움 22%, 희망·의지 22%.
- **해석**: 임을 두고 떠나지 못하는 미련과 그리움의 시입니다.
- **원인**: '강물'(2번), '흐르', '산에'가 평온으로 잡혔지만, 이 시에서 강물은 "어서 따라오라고" 화자를 재촉하는 존재라서 평온과 반대입니다. '다시 더 한 번'의 '다시', '따라가자고'의 '가자'는 희망으로 잘못 세어졌습니다.
- **개선**: 사례 2와 같이 자연 소재를 정서 시어에서 분리하고, '다시'처럼 문맥에 따라 뜻이 갈리는 부사는 사전에서 뺍니다.

### 사례 5. 「산유화」 — 짧은 시어의 오탐
- '갈 봄 여름 없이'의 '봄'이 기쁨·생동으로 두 번 잡혀 기쁨이 25%가 됩니다. 여기서 '봄'은 계절을 나열한 것일 뿐 기쁨과 관련이 없습니다. 한 글자 시어(봄, 꿈, 옛, 죽, 님)는 오탐이 많으므로, 앞뒤 낱말을 함께 보는 규칙이 필요합니다.

## 5. 한계와 개선 방향

- **반어·역설을 읽지 못함**: 사전은 낱말만 보므로 「진달래꽃」, 「먼 후일」('잊었노라'가 실제로는 잊지 못함), 「복종」(복종이 곧 자유) 같은 반어·역설을 그대로 셉니다. 해석 프로필로 보완했지만 프로필 자체가 작성자의 주관입니다.
- **어간 매칭의 오탐**: '아름', '봄', '다시', '믿'처럼 다른 뜻의 낱말 속에 들어 있는 경우를 구분하지 못합니다. 형태소 분석기(예: Kiwi, Okt)를 써서 품사까지 맞추면 줄일 수 있습니다.
- **반복의 과대 반영**: 후렴·수미상관이 있는 시(「논개」, 「향수」, 「초혼」)는 반복된 시어가 비율을 크게 끌어올립니다.
- **소재와 정서의 혼동**: 하늘·강물·물결 같은 자연 소재가 평온으로 세어집니다.
- **개선 방향**: (1) 형태소 분석 후 매칭, (2) 반복 행 중복 제거, (3) 부정어·반어 표현 앞뒤 점수 조정, (4) 수업에서 다룬 BERT 계열 모델로 행 단위 분류 후 사전 결과와 비교(방식 B 추가), (5) 감성 지도(PCA, F-12)와 감정 이미지(F-13) 추가.
